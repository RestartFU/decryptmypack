Server in. ZIP out.

Nothing to install and nothing to upload. Every download moves through the same five stages you see in the status panel.

  1. Cache

    If anyone fetched this server before, the ZIP is already here and starts at once.

  2. Join

    A headless Bedrock client connects to the address you gave, following any server transfer.

  3. Download

    It accepts the server's pack offer and receives every resource pack, chunk by chunk.

  4. Decrypt

    Encrypted packs are unlocked with the keys the server sent, then bundled together.

  5. Ready

    Your browser starts the download. One ZIP, one folder per pack.
